# X 关注清理

一个免费、本地运行的 Chrome / Edge 扩展。点击浏览器里的扩展图标，直接展开工具栏下方的小面板，检查自己的关注列表，取消关注选定范围内未回关的账号，保留互关账号。

Mac 和 Windows 使用同一份扩展；这是浏览器扩展，不是 `.app` 或 `.exe`。不需要服务器、开发者账号或付费 X API。

## 安装

1. 在 [GitHub Releases](https://github.com/jchdante-tech/x-follow-cleaner/releases) 下载 `x-follow-cleaner-v0.1.2.zip`，先解压到一个固定文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后**直接包含 `manifest.json` 的文件夹**，不要选择 ZIP 文件。
5. 在浏览器的扩展菜单里固定「X 关注清理」，方便打开。

更新已有安装时，将新版本解压到原文件夹后，在扩展管理页点「重新加载」。

安装后保留这个文件夹。分享时发送 ZIP 即可，对方按以上步骤安装。也可以直接加载源码中的 `extension` 文件夹。

## 使用

1. 先在同一个 Chrome / Edge 浏览器中登录自己的 X 账号。
2. 点击扩展图标，打开面板并连接 X，核对显示的账号。
3. 选择范围。可以先点「仅检查」查看数量，这一步不会取消关注。
4. 核对面板中的账号和规则后，点击「清理未回关」。工具会重新扫描当前范围，再直接逐个清理；再次扫描用于避免沿用已经变化的检查结果。
5. 启动时会打开并切到独立的 X 工作页，插件面板可能随之收起。再次点击插件图标即可查看进度、暂停或停止，原任务不会重复启动。

范围有三种：

- **全部**：检查当前关注列表中的全部账号。
- **指定账号及较新关注**：从列表顶部到你填写的 `@用户名`，包含指定账号。
- **指定账号及较早关注**：从你填写的 `@用户名`到列表末尾，包含指定账号。

范围依据**当前 X 列表的显示顺序**，不是关注日期。X 页面没有提供准确的逐人关注时间。找不到指定账号时，不会擅自扩大到全部。

「清理」是取消关注，不是删除粉丝。筛选条件是未回关，**没有蓝 V 限定**；蓝 V 和非蓝 V 适用同一规则，已回关的账号保留。

关系判断依据 X 页面当时的回关提示：在支持的页面语言下，同一账号行和关注按钮连续两次完整、稳定地显示，且都没有回关标记，才列入待清理。执行前还会重新核对；出现回关标记则保留，账号或页面状态无法确认则保留。页面提示不等同于通过官方关系接口验证。已发起但未确认结果的操作不计入「已清理」，需查看记录核对。

目前支持英文与简体中文的关系判断。繁体中文及其他语言会保留无法判定的账号；需要使用时先将 X 显示语言切换为英文或简体中文。「已清理」表示工具观察到同一账号的按钮稳定变回「关注」，不是服务器端核验承诺；网络延迟失败仍可能需要人工核对。

范围和未填完的起点会自动保存。面板收起后任务继续，重新打开会恢复进度；运行时保持 X 工作页开启。刷新或关闭工作页后，不会自动继续执行；重新打开后先核对状态。默认没有定时任务，也不会在浏览器启动后自动清理。遇到登录失效、页面异常或限制时会停止继续操作，不把未确认结果算作成功。不能保证 X 永远不会限流。

「一键」指一键开始整个流程，处理仍然逐个进行：每次尝试之间至少等待约 12 秒，另有扫描和核对时间。暂停或停止不会撤回已经发给 X 的请求；这些请求未能确认时会标为待核对。

## 数据与隐私

账号检查、任务状态和清理结果保存在当前浏览器本地，不上传到服务器。扩展使用浏览器中已经登录的 X 网页，不要求你填写密码或导出 Cookie。详情见 [PRIVACY.md](PRIVACY.md)。

## 开发与打包

需要 Node.js 20 或更新版本；扩展运行时无需 Node.js，也没有 npm 运行依赖。

```sh
node --test
node scripts/package.mjs
```

产物为 `dist/x-follow-cleaner-v0.1.2.zip`。打包脚本只收集明确列出的 13 个扩展资源及 README、隐私说明、许可证，共 16 个文件；会拒绝陌生资源和符号链接。测试、研究记录、账号数据和浏览器缓存不属于安装包。它使用 Node.js 标准库生成 ZIP，不调用系统压缩工具。

## 当前验证范围

这是可分享测试版本。已在 macOS Chrome 的独立临时配置中安装扩展，并使用模拟 X 页面验证连接、检查、清理、互关保护和刷新停止。各版本的具体验证记录见源码中的 VALIDATION.md。**未进行真实 X 批量取关测试，也未在 Windows 或 Edge 上完成实机验证**。X 网页结构或语言变化可能需要更新识别逻辑。
